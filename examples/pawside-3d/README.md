# 爪边 Pawside · 桌宠工作室

三种画风依次为 2D、Pawside 3D、像素风。2D 使用银虎斑缅因原画，在 Canvas 2D 上分层绘制眼睛与前爪。Pawside 3D 用 Three.js 绘制墨爪等十款预设，像素风在独立的整数网格上绘制。三套画风使用 Pawside 的输入与动作系统。

2D 预设展示原始插画。捏脸、毛色和预设切换可在 Pawside 3D 与像素风中使用。Cloudflare Pages 的 Git 自动部署、直接上传和重新打包方式见 [部署说明](DEPLOY.md)。

## 打开工作室

- 双击单文件版 `Pawside-Studio.html` 即可离线使用。源码中也可直接打开 `web/index.html`。Pawside 3D 需要支持 WebGL 的浏览器。
- Windows x64 便携包完整解压后打开 `Pawside.exe`。
- Apple 芯片 Mac 便携包完整解压后打开 `Start-Pawside.command`。首次启动会在同一目录展开内附的运行时。
- 桌宠置顶小窗上沿提供换画风、换同桌、拖动、工作室与系统响应控件。启用系统响应后，macOS 可能提示允许辅助功能和输入监控。
- 源码启动需要 Node.js 22.12 或以上版本。首次运行 `npm ci` 和 `node node_modules/electron/install.js` 准备依赖，再用 `npm start` 启动。

## 定制一只猫

1. 在「选同桌」选择预设。点「捏捏这张脸」会切到正脸特写。
2. 调整头宽、眼距、两侧瞳色、耳尖、口鼻、体态和花纹。Pawside 3D 另有部位厚度、材质和侧面视角。照片取色在本机完成。
3. 选择温和、好奇或贪睡，分别会在闲置约 25、45 或 12 秒后开始打盹，对招呼和抚摸的回应时长也不同。
4. 在「收藏」命名并保存，也可导出完整 JSON 或透明 PNG。导入兼容旧版配色与捏脸文件。单文件网页与桌面程序可用角色 JSON 交换设定。

## 试试这些动作

点「键鼠回放」重放 17.26 秒的录屏动作。点「节奏对照」可连续观察慢敲、连打、飞速打字、停手抬眼和长按退格。慢敲时猫会偏头找键。飞速输入时眼睛收窄，肩膀随落键下沉，耳尖稍后跟动。停下一阵密集打字、松开最后一个键，它会短暂抬眼，再慢眨一次。退格时耳朵压向两侧，张嘴露出小牙。

| 输入 | 反应 |
| --- | --- |
| 零星按 A、J | 看向键位，左右爪高抬再落下 |
| 按住 A，再按 S，先松开 S | 同一只爪子从 S 回到仍然按住的 A。2D 与 3D 的爪尖会跟随键帽回弹 |
| 连续敲空格 | 左右爪轮流落在长键的两侧。握鼠标时由空闲爪敲击 |
| 最近 1.25 秒内至少 4 次按下 | 切到连打，缩短行程；左右手按实际键区分工 |
| 同一窗口至少 8 次按下 | 飞速打字，身体前倾，两只猫眯眼的程度不同，爪子贴近键盘 |
| 单按、连按、长按退格 | 单按只看一眼，连按压耳甩尾，长按持续锤键。松手转向鼠标后尾尖仍可拍向键盘右侧 |
| 光标在猫的画面上移动 | 猫看向光标，前爪留在原位。正在打字时视线优先跟随键位 |
| 按住画面内的鼠标，或开启桌面系统键鼠跟随 | 一只爪子搭鼠标，另一只继续打字。快速移动鼠标时瞳孔放大 |
| 按住鼠标左键、右键或中键 | 对应键壳下压，爪尖偏向按住的一侧。两键同按、分开松手时逐键响应 |
| 前后滚动滚轮 | 金色轮齿随方向转动，爪尖跟着拨动，鼠标旁的小箭头指示方向 |
| 按住鼠标，再连续按 J、K、L | 一爪留在鼠标，另一爪跨键。松鼠后连续敲 A、S、D，闲爪收向胸前，停手后落回桌面 |
| 两次 Shift 或点猫头 | 眯眼抬头打招呼。按住猫头来回轻抚，会闭眼侧头蹭手 |
| 闲置达到性格设定的时间 | 垂头闭眼打盹，输入后醒来 |

安静待机的目标为每秒 20 帧，跟随光标时约 28 帧，熟睡时约 12 帧。敲键、按鼠标和抚摸会立即请求下一显示帧。网页试玩离开视口或切到后台时暂停渲染。

## 输入隐私

- 工作室的普通试打框保留键位反馈。聚焦密码、一次性验证码或显式标记的隐私框时，猫会捂眼，清除落点、键帽高亮、速度和气泡。离开隐私框后恢复。测试请使用随意字符。
- 在其他应用里，系统监听只把每 400 毫秒的键盘活动归入三个粗略速度档。桌面猫交替空拍，键帽和气泡不显示具体键位，退格混在普通按键中。这个策略也覆盖系统无法识别的自绘输入框。
- Windows 的 UI Automation 和 macOS 的辅助功能属性可提示系统密码焦点，识别到时整段捂眼。这些探测只读控件属性。平台权限或应用暴露的属性会影响识别。Linux 使用匿名节奏。退出监听后停止探测。

## 开发与验证

`npm test` 运行输入状态机、角色预设与皮肤文件回归测试。`npm run reference:check` 检查键鼠回放。`node tools/build-studio.cjs Pawside-Studio.html` 生成离线单文件。

`web/looks.js` 定义跨画风的角色字段。`web/legacy-2d.js` 负责旧版原画的分层驱动，`web/pixel.js` 绘制整数网格的像素猫，`web/scene.js` 负责 Pawside 3D。`web/drawing.js` 共用画面投影、输入命中和渲染入口。`web/motion.js` 维护动作，`desktop/` 连接桌面窗口。`pawReview.begin(pet,width,height,action,renderStyle)` 和 `pawReview.frame(seconds)` 可重放确定性输入，`renderStyle` 继续支持历史标识 `paper`（2D）、`volume`（Pawside 3D）与 `pixel`（像素风）。

本项目的原创代码采用 Apache-2.0；Three.js 采用 MIT 许可，文件位于 `web/vendor/THREE-LICENSE`。桌面运行时使用 Electron；系统键鼠使用 uiohook-napi，仅在用户启用时加载。各组件保留各自许可证。

## 动作参考

对照小只桌宠官网演示和提供的录屏，观察侧身握鼠、胸肩前倾、停拍与尾尖落点。录屏没有原始键鼠事件，对照影片中的输入根据可见动作重演。[小只桌宠](https://xiaozhilittleone.com/zh/)

参考 KuroCat 的逐爪键位追踪、空格交替落爪和 3D 键面定位。Pawside 的 2D 前爪按原画的肩部和爪垫位置变形，3D 前爪按实例化键帽的表面高度定位。3D 场景只构建当前角色，切换角色时释放上一只猫的网格和材质。[KuroCat 持键追踪](https://github.com/qianyiai/KuroCat/blob/1df9f3f3020be58d3da49b00880510bfe27c8a10/src/catEngine.ts#L3287-L3304) · [KuroCat 3D 落爪](https://github.com/qianyiai/KuroCat/blob/1df9f3f3020be58d3da49b00880510bfe27c8a10/src/catEngine3d.ts#L4268-L4291)
