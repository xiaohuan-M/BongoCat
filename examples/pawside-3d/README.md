# 爪边 · Pawside 3D

墨爪是一只金眼黑猫，栗酥是暖橘色长毛缅因，有浅奶油色胸毛、口鼻和带环纹的尾尖。两只小猫坐在一把 62 键的小键盘前，根据输入频率调整抬爪高度、出手时间、眼睛和身体姿态。

## 打开

- 网页工作室：直接打开 `web/index.html`。画面支持键盘、鼠标和触屏，可切换角色、拍透明 PNG 和导入导出配色。
- Windows x64 便携包：完整解压后双击 `Pawside.exe`。
- Apple 芯片 Mac 便携包：完整解压后打开 `Start-Pawside.command`。首次启动会在同一目录展开内附的 Electron 运行时。
- 源码启动：安装 Node.js 22.12 或以上版本，运行 `npm ci`、`node node_modules/electron/install.js` 和 `npm start`；也可用本目录对应的启动脚本。首次安装依赖需要联网。
- 桌面小窗置顶。鼠标移到顶部可换猫、拖动窗口、打开工作室或退出。点「跟随系统键鼠」后，在其他窗口打字也会触发动作。macOS 按系统提示允许辅助功能和输入监控，可随时点「暂停系统响应」。锁屏和休眠会暂停监听。
- 这个独立桌面伴侣与 BongoCat 的 Rust 应用分开启动。网页、桌面和演示共用 `web/` 中的场景与动作。旧版插画模型仍可从 BongoCat 原有模型库打开。

## 试试这些动作

点「原片复刻」重放 17.26 秒的录屏动作。点「表情对照」可连续观察慢敲、连打、飞速打字、停手抬眼和长按退格。慢敲时猫会偏头找键。飞速输入时眼睛收窄，肩膀随落键下沉，耳尖稍后跟动。停下一阵密集打字、松开最后一个键，它会短暂抬眼，再慢眨一次。退格时耳朵压向两侧，张嘴露出小牙。

| 输入 | 反应 |
| --- | --- |
| 零星按 A、J | 看向键位，左右爪高抬再落下 |
| 最近 1.25 秒内至少 4 次按下 | 切到连打，缩短行程；左右手按实际键区分工 |
| 同一窗口至少 8 次按下 | 飞速打字，身体前倾，两只猫眯眼的程度不同，爪子贴近键盘 |
| 单按、连按、长按退格 | 单按只看一眼，连按压耳甩尾，长按持续锤键。松手转向鼠标后尾尖仍可拍向键盘右侧 |
| 移动鼠标后按键 | 黑猫侧身，一只爪子搭鼠标，另一只继续打字；快速移动鼠标会放大瞳孔 |
| 按住鼠标左键、右键或中键 | 对应键壳下压，爪尖偏向按住的一侧。两键同按、分开松手时逐键响应 |
| 前后滚动滚轮 | 金色轮齿随方向转动，爪尖跟着拨动，鼠标旁的小箭头指示方向 |
| 按住鼠标，再连续按 J、K、L | 一爪留在鼠标，另一爪跨键。松鼠后连续敲 A、S、D，闲爪收向胸前，停手后落回桌面 |
| 两次 Shift 或点猫头 | 眯眼抬头打招呼。按住猫头来回轻抚，会闭眼侧头蹭手 |
| 闲置约 25 秒 | 垂头闭眼打盹，输入后醒来 |

安静待机时场景按每秒 30 帧更新，熟睡时降到 12 帧。新的键鼠输入会立即恢复按屏幕刷新率更新。普通按键的系统自动重复不计入速度。上传宠物照片后可点毛发取色，或手选毛色和瞳色，分别保存两只猫的方案。此版本提供两种预建体型；照片只参与本地取色。工作室的键名气泡从落键处短暂上浮，桌面小窗跟随工作室普通试打时显示圆点。图片与配色在本机处理。

## 输入隐私

- 工作室的普通试打框保留键位反馈。聚焦密码、一次性验证码或显式标记的隐私框时，猫会捂眼，清除落点、键帽高亮、速度和气泡。离开隐私框后恢复。测试请使用随意字符。
- 在其他应用里，系统监听只把每 400 毫秒的键盘活动归入三个粗略速度档。桌面猫交替空拍，键帽和气泡不显示具体键位，退格混在普通按键中。这个策略也覆盖系统无法识别的自绘输入框。
- Windows 的 UI Automation 和 macOS 的辅助功能属性可提示系统密码焦点，识别到时整段捂眼。这些探测只读控件属性。平台权限或应用暴露的属性会影响识别。Linux 使用匿名节奏。退出监听后停止探测。

## 开发与验证

`npm test` 运行输入状态机回归测试。`node tools/build-studio.cjs Pawside-3D-Studio.html` 输出可断网使用的单文件工作室。原始页面与独立 HTML 都使用内置的 Three.js r160。模型、毛色、键帽及重心/四肢的更新在 `web/scene.js`，速度分层与输入在 `web/motion.js`，交互入口在 `web/studio.js`，桌面桥接在 `desktop/`。预览和导出使用同一摄像机。通过 `pawReview.begin(pet,width,height)` 和按升序调用 `pawReview.frame(seconds)` 可重放工作室中的动作演示，共 12.55 秒。第四个参数传入 `hands` 可重放「键鼠合奏」的 11.65 秒输入，传 `tempo` 则重放「表情对照」的 10.72 秒输入。

本项目的原创代码采用 Apache-2.0；Three.js 采用 MIT 许可，文件位于 `web/vendor/THREE-LICENSE`。桌面运行时使用 Electron；系统键鼠使用 uiohook-napi，仅在用户启用时加载。各组件保留各自许可证。

## 动作参考

对照小只桌宠官网演示和提供的录屏，观察侧身握鼠、胸肩前倾、停拍与尾尖落点。录屏没有原始键鼠事件，对照影片中的输入根据可见动作重演。[小只桌宠](https://xiaozhilittleone.com/zh/)

参考 KuroCat 的两种实现，将视线与转头分开平滑，快速移动鼠标时暂时放大瞳孔；敲键后的空闲爪收回胸前。两只角色、几何、动作与符号由本项目独立绘制。[chanke17/KuroCat](https://github.com/chanke17/KuroCat) · [qianyiai/kurocat](https://github.com/qianyiai/kurocat)
