# 从原片到第二只猫

用户提供的录屏长约 17.26 秒。键盘在猫坐直、握鼠和打字时都留在桌上。原片只有画面，具体按键与时间按可见动作推定。下面的节点用于复刻，密码保护和摸头是额外互动。

| 取样时间 | 画面证据 | 验收时看哪里 |
| --- | --- | --- |
| 0.47 秒 | 侧身搭鼠标 | 爪尖搭上鼠标，肩与腕之间有转折，后脚留在原地 |
| 2.13 秒 | 身体回到键盘中央 | 两爪分工，空闲爪能收回，短按仍有一次接触 |
| 3.83 秒 | 低头锤键 | 猫压耳，键名在接触后出现；连打和生气的姿态能分辨 |
| 8.54 秒 | 已握鼠，尾尖仍拍右侧 | 看前爪和尾巴是否能同时做不同的事，尾尖靠近键盘右缘 |
| 13.58 秒 | 还在鼠标旁，情绪已平复 | 尾尖抬起，怒符消失 |
| 15.30 秒 | 坐直待机 | 两只前爪收回，键盘仍在原位；结尾播放器浮层是原录屏界面 |

## 复用步骤

1. **截原片。** 固定裁切，按键盘宽度对齐机位。先写下能观察的姿态，再估计输入事件。为每个节点保留秒数。复刻素材只用于对照。
2. **编排输入。** 时间表在 `web/reference.js`。工作室「原片复刻」和核对脚本都读这一份。通过鼠标位置、按下和松开驱动正常动画。
3. **分别检查接触和余动。** 看后脚是否滑动，手腕是否连接，爪尖是否压到目标，尾尖是否穿过桌面。按住鼠标打字、单按退格、连按退格、长按后改握鼠分开试。
4. **换形象。** 墨爪作为对照片，栗酥沿用时间表和动作控制器。重点复查长毛猫的爪垫、耳尖、尾尖和胸毛遮挡。为形象调整模型尺寸或附着点，两只猫使用同一套事件。
5. **重复取帧。** 从开发包目录运行 `npm ci` 和 `node node_modules/electron/install.js` 安装依赖与 Electron 运行时，然后运行下方命令。取帧使用工作室的真实 Three.js 场景、720 × 520 机位和 30 fps 时间轴。每次输出一个新的目录，含两只猫的 12 张透明图和对应秒数清单。
6. **验收输入边界。** 在普通试打框按 A、J 与退格，再切入隐私试打框。使用两组不同的测试字符，检查捂眼姿态、键帽、气泡和速度是否一致。离开后检查第一次普通按键和鼠标能否响应。

```sh
npm test
npm run reference:check
npm run reference:frames -- ./frames
```

自动检查覆盖姿态状态和关键坐标。最终相似度仍需看原片及两种形象的实际取帧。逐键演示在工作室内复现，外部应用用匿名节奏。两种形象已经走完同一套检查。开发包内的 `Reference-Take/` 附本次导出的 12 张实际渲染图和清单。

### 脸、坐姿和爪边高光

把原片和实际画面按键盘前缘的宽度对齐，在 0.47 秒看侧脸、肩背和握鼠的弧度，在 15.30 秒看正脸和坐姿。用双眼到键盘前缘的垂直距离核对头高，以键盘宽度为单位。2.13 秒原片约 0.69，当前墨爪约 0.62。3.83 秒原片约 0.68，当前约 0.59。以原片的动作时机为基准。新版墨爪把脸颊、额头和下巴连成连续圆弧，眼睛以深瞳、暖色虹膜和两处大小不同的反光表现视线。身形比例保留这一版的设计取舍。

先在正面和侧面检查坐骨、后腿和前脚掌是否连成自然的受力姿势，再在 420 × 288 的透明小窗重放慢敲、锤键和捂眼。检查贴着胸口的前爪是否有一段可见的高光、肩根的线是否自然收住，以及视线转动时眼内反光是否仍清晰。再用栗酥运行同一段，观察长毛胸口、绿色眼睛和耳尖的轮廓。
